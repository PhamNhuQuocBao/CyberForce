# CF-304 — Kali AttackBox qua Guacamole (2026-10-14)

## Phạm vi được duyệt

Người dùng duyệt Kali AttackBox qua Guacamole trước; inject cờ động thuộc task riêng. `guacd` dùng chung, chỉ nối vào mạng riêng của lab khi AttackBox hoạt động và ngắt khi dừng. Ưu tiên kiểm thử web desktop.

## Triển khai

- Compose build image Kali XFCE/VNC kèm Nmap, Burp Suite, Metasploit, Wireshark, SQLmap, John; AttackBox chạy theo phiên lab, không đặc quyền, read-only rootfs, tmpfs home và giới hạn CPU/RAM/PID. Screensaver bị tắt để VNC không hiện màn hình khóa.
- Go orchestrator quản lý start/status/stop AttackBox, nối/ngắt `guacd` khỏi mạng lab và làm sạch AttackBox khi dừng/reap lab. `guacd` chỉ lắng nghe ở IP mạng Compose, không công bố cổng host hay lắng nghe trên IP mạng lab.
- Go bridge tự chọn VNC target/password từ container của phiên, chỉ nhận lệnh Guacamole cần cho tương tác; trình duyệt không thể chọn host/port tùy ý.
- API Core kiểm tra quyền phòng, chủ sở hữu phiên đang chạy và lease; cấp ticket WebSocket 30 giây dùng một lần cho stream. Web hiển thị Kali trong tab AttackBox của workspace, kết nối lại và chuyển clipboard hai chiều.
- Desktop VNC cố định 1280×800; Canvas co giãn theo chiều rộng khung web. Lệnh resize gửi trước frame đầu làm guacd ngắt phiên, nên frontend không gửi resize sớm. Đổi độ phân giải Xvfb thực chưa triển khai.

## Kiểm chứng

- `docker compose up -d --build --wait web` và full stack healthy. Go tests qua trên Go 1.24 container; API tests 110/110 qua trên schema PostgreSQL `cf304_test_20261014` và Redis DB 15; web build/lint qua.
- Browser desktop: mở lab `sqli-basics-101`, Start AttackBox, thấy XFCE/taskbar, mở terminal Kali và chạy `nmap -sT -Pn -p80 <target IP>`; cổng 80 của target mở.
- Clipboard browser → Kali: `cf304_browser_to_kali_20261014` đọc đúng bằng `xclip` trong AttackBox. Kali → browser: `cf304_kali_to_browser_20261014` xuất hiện trên nút sao chép và clipboard trình duyệt đúng nguyên văn.
- Target không truy cập được `guacd` qua IP mạng lab/port 4822; gateway trên mạng Compose vẫn kết nối. Lab và AttackBox smoke test đã dừng; tài khoản smoke test `cf304_smoke_20261014` đã xóa.

## Giới hạn và tiếp nối

- Chưa đo độ trễ đầu cuối <80ms dưới tải hoặc trên mạng khác máy local. Chưa đổi độ phân giải Xvfb thực; hiện chỉ co giãn Canvas.
- Bước tiếp nối đã thay Xvfb/x11vnc bằng TigerVNC và đổi độ phân giải desktop thật; xem [CF-304-RESIZE.md](CF-304-RESIZE.md). SLA `<80ms` vẫn chưa đo.
- Chưa inject cờ động vào target/AttackBox; triển khai theo task riêng được duyệt sau.
