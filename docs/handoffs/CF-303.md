# CF-303 — Web Terminal (2026-10-13)

## Quyết định được duyệt

Người dùng duyệt terminal **sidecar** riêng trong mạng Docker nội bộ của từng lab, thay vì `docker exec` vào target có thể lộ challenge files/flag. Luồng là browser xterm → API Core WebSocket ticket một lần → Go Orchestrator → Docker TTY. Sidecar Alpine chạy `nobody`, read-only root, bỏ mọi capability, no-new-privileges, 0.5 CPU, 512 MB RAM, 128 PID và tmpfs `/tmp` tối đa 512 MB. Host hiện dùng overlay2/extfs, không bảo đảm quota writable layer 2 GB; người dùng đã duyệt tmpfs 512 MB thay thế cho host này. Không có mount filesystem target hay Docker socket trong sidecar. Mạng lab `internal` từ CF-301 chặn egress Internet.

## Triển khai

- Go tạo sidecar khi spawn lab, mở shell TTY và resize, xóa sidecar trước target/network khi stop hoặc reaper dọn. WebSocket input binary, resize JSON text, output binary; ngắt sau 15 phút không có phím gõ.
- Compose có bước `terminal-image` kết thúc mã 0 trước orchestrator để image Alpine được tải/tag vào Docker daemon trong cùng lệnh `docker compose up -d --build --wait`; sidecar không cần tải image lúc learner bấm Start.
- API `GET /api/v1/rooms/:slug/lab`, `POST /:slug/terminal-ticket`, `GET /:slug/terminal` (WebSocket). Ticket Redis 30 giây, dùng một lần, chuyển qua `Sec-WebSocket-Protocol` để không vào URL log. Kiểm tra Origin, quyền phòng, chủ phiên, trạng thái/TTL và token logout; kết nối đang mở kiểm tra lại mỗi 15 giây.
- Workspace desktop hiển thị start/stop/extend, target IP, đồng hồ và trạng thái grace. `WebTerminal` dùng xterm/fit, tự resize, bàn phím Ctrl+C, nút copy/paste và reconnect. Không kiểm thử giao diện mobile theo ưu tiên người dùng.
- Không đổi DB schema. Thêm `@fastify/websocket`, `ws`, `@types/ws` và `github.com/gorilla/websocket` theo kế hoạch đã duyệt.
